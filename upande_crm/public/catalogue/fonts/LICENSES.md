# Bundled catalogue fonts

All files here are Latin-subset WOFF2 builds from Fontsource
(https://fontsource.org), shipped so buyer pages make no third-party requests.
Every family is licensed under the SIL Open Font License 1.1
(https://openfontlicense.org): Archivo, Archivo Narrow, Newsreader, Fraunces,
Instrument Sans, Spectral, Cormorant Garamond, IBM Plex Serif, Space Grotesk,
Inter Tight, Bodoni Moda, Work Sans.

Each folder is one font pair (see FONT_PAIRS in upande_crm/catalogue_templates.py)
and its fonts.css declares the faces the page loads for that pair.
